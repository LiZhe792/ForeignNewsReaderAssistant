# ForeignNewsReaderAssistant

**Margin 知刊 · 外刊学习助手**

[15 TTS 朗读](#15-tts-朗读) 支持从单词到全文的听读与跟读练习。

使用 **Python + Flask + SQLite** 完成赛题 1 的五项基础要求。前端使用原生 HTML / CSS / JavaScript，无需 Node.js 或单独的数据库服务。

本项目使用本地 **PyCharm 直接运行 app.py**，当前包含五项基础功能、「05 阅读器扩展」和「06 阅读流畅性设计」，不提供批处理启动脚本。

## 在 PyCharm 中运行

1. 用 PyCharm 打开 `ForeignNewsReaderAssistant` 项目文件夹。
2. 在 **Settings → Project → Python Interpreter** 中选择 Python 3.10 或更新版本，推荐 Python 3.12。
   - 项目已有虚拟环境时，可选择 `.venv/Scripts/python.exe`。
   - 也可以通过 PyCharm 为项目新建虚拟环境。
3. 在 PyCharm 的 Terminal 中安装依赖，确认终端使用项目解释器：

   ```bash
   python -m pip install -r requirements.txt
   ```

4. 右键根目录的 **app.py → Run 'app'**。
5. 在浏览器打开 **http://127.0.0.1:5000**。

在 PyCharm 中点击停止按钮即可关闭服务。下次运行时，已保存的学习记录会自动加载。首次安装依赖需要联网。

数据与示例文件路径均相对于项目代码所在位置解析，不依赖工作目录。如果端口被占用，可以在 Run Configuration → Environment variables 中设置 `PORT=5001`，再访问对应端口。

## 基础功能

| 赛题要求 | 当前实现 |
| --- | --- |
| 文章获取与阅读器 | 公开网页链接提取、粘贴英文正文、内置 5 篇原创示例；分类与搜索；字号 16–28 px、行距 1.4–2.4 倍 |
| 划词查词与基础释义 | 单击或划选一个英文单词；显示音标、词性、释义；支持输入单词查询 |
| 生词本 | 收藏、手动添加、删除、编辑释义与笔记、搜索；手动标记初次遇见 / 正在学习 / 已掌握 |
| 阅读进度与打卡日历 | 自动保存进度和最近阅读位置、标记已读、活跃阅读自动打卡、手动打卡、月历及阅读统计 |
| 文章难度标注 | 估算易读度，标注 A2 / B1 / B2 / C1 / C2 参考等级，显示词数与预计阅读时长 |

## 05 阅读器扩展

打开一篇文章，使用顶部工具栏中的「阅读设置」「目录」「专注」「全屏」「查词」和「操作帮助」。

| 功能 | 使用方式 |
| --- | --- |
| 字体切换 | Georgia、Times New Roman、Arial、Consolas 四种字体方案，使用本机字体及对应后备字体 |
| 内容宽度 | 正文最大宽度 560–1200 px；窗口较窄时自动收缩 |
| 段落间距 | 0.5–3 em，随正文字号缩放；字号与行距仍可单独调整 |
| 阅读主题 | 浅色、深色、护眼三种主题，覆盖阅读区域、工具栏、查词面板与弹窗 |
| 专注模式 | 隐藏主导航和顶部应用栏；阅读工具栏保留，可随时退出或打开查词 |
| 全屏阅读 | 点击「全屏」或按 G，由浏览器进入全屏；再次点击或按 Esc 退出。浏览器不支持时会提示使用专注模式 |
| 单栏与双栏 | 双栏按每行先左后右阅读，再向下阅读；正文区域不足 680 px 时自动显示单栏，保留双栏偏好 |
| 段落编号 | 在正文左侧显示编号，编号不混入复制的正文和单词语境 |
| 目录导航 | 按真实段落生成目录，以原文开头作预览；点击定位，不修改文章地址 |
| 快捷键 | F 专注、G 全屏、T 目录、S 设置、N 编号、C 单双栏、[ / ] 上下段、− / + 字号、空格 / Shift 空格翻屏、Home / End 首尾、? 帮助 |
| 手机手势 | 在正文中向左轻扫到下一段，向右轻扫到上一段；上下滚动、长按选词和双指缩放保持浏览器行为 |

设置自动保存在本机 SQLite 数据库，刷新页面或重新运行后继续生效；全屏必须由用户主动开启。阅读设置提供「恢复默认」，保存失败时可以重试。

快捷键在输入框、按钮、链接、可编辑区域和弹窗中不会触发，也不会覆盖 Ctrl、Command 或 Alt 组合键。可分别关闭快捷键与手机手势。Esc 保留为退出或关闭操作。

调整字体、间距、宽度、排版及窗口大小时，阅读器按当前段落及段内位置恢复视图；重新打开文章时仍使用原有阅读位置记录。改变排版本身不会增加已读进度。目录跳转和正常滚动继续记录阅读位置。

## 06 阅读流畅性设计

文章工具栏下方可切换「流畅阅读 / 精读模式」，并打开「本段生词」或「待查词」。默认使用流畅阅读。

| 功能 | 使用方式 |
| --- | --- |
| 流畅阅读 | 点词或划词先暂存，不请求词典、不弹出释义；正文使用完整阅读空间 |
| 精读模式 | 点词打开查词卡片；任何模式都可通过工具栏「查词」主动输入查询 |
| 释义折叠 | 查词卡片默认折叠，点「展开释义」查看；可在阅读设置中调整默认行为。待查列表始终在展开时才查询 |
| 段落集中处理 | 含待查词的段末显示「读完此段 · 处理…」，也可打开「本段生词」。列表按段落筛选，逐词展开、收藏或移出 |
| 暂存待查词 | 按文章和段落保存到本机，刷新和重启后仍在；同一段落的相同单词不重复添加。手动查询的词归入「手动记录」 |
| 学习提示密度 | 阅读设置提供安静、适中、详细：安静隐藏正文标记与主动提醒；适中仅标记每段首次出现的学习词；详细标记所有学习词并显示辅助说明 |
| 已掌握词减少提示 | 默认不主动标记已掌握词；可关闭该选项。手动点词、查词、暂存仍然有效 |
| 查词后保持位置 | 查词面板不挤动正文；关闭集中处理面板或点击「继续阅读」回到原处。异步释义返回不会把正在滚动的读者拉回旧位置 |
| 阶段性学习提醒 | 默认每 10 分钟前台活跃阅读显示轻提示，不抢焦点；可整理待查词、5 分钟后提醒或继续阅读。设置范围 0–60 分钟，0 关闭 |

提醒计时按本次打开文章累计，离开文章后重新开始；页面隐藏、弹窗、查词浮层、查词输入焦点或超过 60 秒无操作时暂停。安静档不主动提醒。滚动或跳段不会被当作已读确认，也不会自动把待查词标记为掌握。

暂存只记录单词和原文语境，不会自动加入生词本。收藏待查词与移出待查列表在同一事务中完成；已收藏的词保留原释义、笔记和掌握度。未收录的词可手填释义；查询或保存失败时保留记录并提供重试。

## 使用流程

1. 打开示例文章，或通过「导入文章」添加英文材料。粘贴导入至少需要 40 个英文单词。
2. 在阅读设置中调整字体、字号、间距和主题，选择流畅阅读或精读模式。
3. 流畅模式中先暂存生词，读完一段再展开释义、加入生词本；精读模式可随时点词查阅。也可以手动添加词条。
4. 在「我的生词」中标记掌握度，按需编辑或删除词条。掌握度只记录学习状态。
5. 阅读结束后点击文章末尾的「标记为已读」，在「学习足迹」查看日历与累计阅读情况。

## 15 TTS 朗读

升级后，在 PyCharm 终端重新运行 `python -m pip install -r requirements.txt`，再运行 `app.py`。打开文章，点击工具栏「朗读」。此功能使用 [edge-tts](https://github.com/rany2/edge-tts) 连接 Edge 在线语音服务，无需填写 API 密钥。首次生成需要联网，已缓存的音频可在本地服务运行时断网播放。

| 功能 | 使用方式 |
| --- | --- |
| 单词、句子、段落与全文 | 选择朗读范围后点击「按范围朗读」；正文划选一个单词会填入单词输入框，查词卡片也有「朗读单词」。全文按正文句子顺序播放 |
| 音色与英美口音 | 展开「音色与跟读设置」，选择美式 Aria / Guy 或英式 Sonia / Ryan，共四种音色；切换音色会从当前句开头重新准备音频 |
| 语速调整 | 0.5–2.0 倍速，播放时实时生效并尽量保持音高；修改语速复用同一份音频 |
| 播放、暂停与继续 | 暂停后从原音频位置继续；提供停止、上一句、下一句与当前句音频进度拖动。生成期间暂停，音频返回后仍保持暂停 |
| 点击句子起播 | 开启对应选项后，点击正文从该句向后朗读，也可用 Tab 定位句子后按 Enter；关闭后恢复原有点词查词 / 暂存行为 |
| 逐句高亮 | 正文高亮当前朗读句子；播放、暂停和换句与高亮同步，停止或离开文章时清除 |
| 自动跟随滚动 | 当前句离开可视区域时滚动定位；手动滚动会暂缓跟随，点「定位当前句」恢复；弹窗打开时不自动滚动正文 |
| 句段循环 | 选择单句循环，或循环当前播放范围中的同一段；要练习完整段落，可先选「当前段落」再设段落循环。切回顺序播放可继续后文或列表下一项 |
| 音频缓存 | 播放过的内容自动缓存，并预备下一句；可主动缓存本文全部音频、取消缓存或清理缓存。清理音频不会删除列表或学习记录 |
| 播放列表 | 将单词、句子、段落或全文加入列表；支持去重、上移 / 下移、移除、清空、刷新与按顺序连播，可跨文章自动继续 |

朗读偏好和列表保存在 SQLite 中，刷新及重启后仍在；刷新页面不会自动播放。手动离开阅读器会停止朗读，列表自动切换文章时会继续播放下一项。收起播放器会保留当前播放状态，可随时从工具栏重新打开。

音频按文字与音色区分，保存在 `instance/tts_cache/`，不会上传 Git。默认最多占用 **128 MB**，空间不足时清理最近最少使用的音频；取消预缓存会保留已完成部分，当前已发出的请求可能仍完成缓存。删除文章会删除它在播放列表中的条目，独立单词条目保留；音频缓存可单独清理。

断句保留原文内容，处理常见英文缩写、小数、问号、引号等；极长句或无标点段落会拆成不超过 1800 字符的朗读片段。自动断句属于规则估算，特殊缩写可能需要按段落朗读。列表最多 100 项。

语音服务会接收当前需要生成的文字；打开播放器、查看列表和调整阅读设置不会自动发送文字。服务或网络不可用时会提示错误并保留播放位置，不会假装正在朗读；可点击「重试」。浏览器若阻止自动播放，会提示点击「继续」。外部语音服务的可用性取决于服务提供方。

## 实现说明

### 阅读与记录

精读模式下，宽屏查词结果显示在正文右侧；流畅模式、窄屏、专注或全屏模式使用可关闭的浮动面板。阅读设置保存在本地数据库。

阅读时每约 15 秒保存一次，离开阅读器时也会保存。最大阅读进度不会因向上滚动而减少；最近阅读位置单独记录，重新打开文章时恢复。滚动最多记录到 99%，点击「标记为已读」后更新为 100%。

计时仅在页面前台、没有弹窗、最近 60 秒内有点击 / 滚动 / 键盘等操作时累计，属于活跃阅读时间的近似值。日期采用北京时间。异常断网或突然关闭进程时，最后尚未提交的一小段记录可能丢失。

### 文章获取与词典

网页提取会识别正文段落并过滤导航、脚本等。登录、付费或动态加载页面可能无法自动提取，此时可以粘贴正文。内置文章为项目原创教学示例，并非真实媒体报道的转载。

查词优先使用 `data/dictionary.json` 中的英汉词库，并处理一些常见词形；未收录的词联网查询 Free Dictionary API，返回英英释义并缓存。没有查到时会明确提示，允许手动填写释义。

### 难度标注

按平均句长和近似音节数计算 Flesch Reading Ease：

```text
206.835 - 1.015 × 平均句长 - 84.6 × 平均每词音节数
```

参考映射：85 及以上 A2、65–85 B1、45–65 B2、25–45 C1、低于 25 C2。该等级只是选文参考，不是正式 CEFR 测评。阅读时长按每分钟 180 词估算。

## 项目结构与数据

下列目录和表格说明阅读器的基础数据。朗读另外使用 `tts_playlist` 表保存列表，在 `settings` 表保存朗读偏好，生成的 MP3 保存在 `instance/tts_cache/`。

```text
ForeignNewsReaderAssistant/
├── app.py                    # PyCharm 运行入口、Flask API
├── requirements.txt          # Flask、Beautiful Soup、edge-tts
├── newsreader/
│   ├── db.py                 # SQLite 初始化、旧库迁移、北京时间
│   ├── learning.py           # 词数与阅读难度估算
│   ├── sentences.py          # 保留原文的句段切分
│   ├── speech.py             # 朗读设置、音频 API 与持久化列表
│   ├── tts_audio.py          # Edge 语音生成、并发去重与音频缓存
│   ├── preferences.py        # 阅读设置默认值、校验与兼容读取
│   ├── reading_flow.py       # 待查词 API、段落语境与事务式收藏
│   ├── content.py            # 正文提取、基础查词、释义缓存
│   └── network.py            # 公开网页访问、重定向与大小限制
├── data/
│   ├── articles.json         # 原创示例文章
│   └── dictionary.json       # 内置英汉词库
├── templates/index.html      # 页面与表单
├── static/
│   ├── app.js                # 基础功能交互
│   ├── speech.js             # 朗读、跟随高亮、循环与播放列表
│   ├── speech.css            # 朗读播放器与移动端布局
│   ├── reader.js             # 阅读器设置、目录、快捷键与手势
│   ├── reader.css            # 阅读器主题、双栏与响应式样式
│   ├── reading-flow.js       # 流畅/精读、待查列表与阶段提醒
│   ├── reading-flow.css      # 学习节奏、提示密度和面板样式
│   ├── style.css             # 桌面与窄屏样式
│   └── favicon.svg
├── tests/                   # 基础功能、迁移与阅读设置测试
└── instance/margin.sqlite3   # 首次运行自动创建的本地数据库
```

当前数据库使用 `articles`、`vocabulary`、`pending_words`、`checkins`、`settings`、`dictionary_cache` 六张业务表。升级到 06 会自动创建待查词表，沿用原有阅读设置和学习数据。

从旧版升级时，程序会先备份原库为 `instance/margin-before-basic.sqlite3`，再清理已移除功能的表和字段，保留文章、生词、掌握度、笔记、阅读进度、打卡记录和支持的阅读设置。该转换只在检测到旧表结构时执行。基础版升级到阅读器扩展使用原有设置表，新增设置缺省时自动采用默认值。

删除文章会保留已收藏词汇与历史阅读统计，并清理该文章的待查词。备份个人数据时，先停止程序，再复制 `instance/margin.sqlite3`。

## 测试

在 PyCharm 的 Terminal 中运行：

```bash
python -m unittest discover -s tests -v
```

测试使用临时数据库，外部网络请求使用模拟响应，不修改个人学习数据。覆盖基础接口、持久化、查词缓存、词条管理、阅读设置边界与原子保存、异常设置回退、待查词去重与文章隔离、收藏事务与旧数据升级、打卡统计，以及已移除接口不可访问的检查。

可选的前端逻辑回归测试需要 Node.js 20 或更新版本，无需安装 npm 依赖：

```bash
node --test tests/test_frontend.cjs tests/test_speech_player.cjs
```

这组测试运行真实的前端脚本，使用最小 DOM 替身和模拟请求，覆盖删除失败后继续保存、断网后计时补存、并发保存、划词查词及生词表单校验，以及朗读暂停继续、换句语速、迟到响应隔离、句段循环和缓存取消。Python 测试还覆盖 TTS 断句、偏好与列表持久化、音频范围请求、离线缓存、并发去重、缓存清理与容量淘汰。它不替代真实浏览器中的布局和端到端交互检查；运行应用本身仍然只需要 Python。

可选的真实浏览器检查使用 Playwright，仍只操作临时数据库：

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node --test tests/test_reading_flow_browser.cjs
```

浏览器检查覆盖流畅/精读模式、释义折叠、段落待查词的刷新恢复与收藏、提示密度和已掌握词、网络失败重试、阶段提醒，以及桌面和手机视口下的阅读位置。异步列表更新会保留正在编辑的释义、焦点和光标；段末按钮出现或消失时按原文词语保持阅读位置。

本项目为本地单用户版本，默认仅监听 `127.0.0.1`。
