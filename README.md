# ForeignNewsReaderAssistant

**Margin 知刊 · 外刊学习助手**

使用 **Python + Flask + SQLite** 完成赛题 1 的五项基础要求。前端使用原生 HTML / CSS / JavaScript，无需 Node.js 或单独的数据库服务。

本项目使用本地 **PyCharm 直接运行 app.py**，当前包含五项基础功能、「05 阅读器扩展」、「06 阅读流畅性设计」和「24 导出与外部工具联动」，不提供批处理启动脚本。

## 在 PyCharm 中运行

1. 用 PyCharm 打开 `ForeignNewsReaderAssistant` 项目文件夹。
2. 在 **Settings → Project → Python Interpreter** 中选择 Python 3.10 或更新版本，推荐 Python 3.12。
   - 项目已有虚拟环境时，可选择 `.venv/Scripts/python.exe`。
   - 也可以通过 PyCharm 为项目新建虚拟环境。
3. 在 PyCharm 的 Terminal 中安装依赖，确认终端使用项目解释器：

   ```bash
   python -m pip install -r requirements.txt
   ```

4. 右键根目录的 **app.py → Run 'app'**。
5. 在浏览器打开 **http://127.0.0.1:5000**。

在 PyCharm 中点击停止按钮即可关闭服务。下次运行时，已保存的学习记录会自动加载。首次安装依赖需要联网。

数据与示例文件路径均相对于项目代码所在位置解析，不依赖工作目录。如果端口被占用，可以在 Run Configuration → Environment variables 中设置 `PORT=5001`，再访问对应端口。

## 05 阅读器扩展

打开一篇文章，使用顶部工具栏中的「阅读设置」「目录」「专注」「全屏」「查词」和「操作帮助」。

| 功能 | 使用方式 |
| --- | --- |
| 字体切换 | Georgia、Times New Roman、Arial、Consolas 四种字体方案，使用本机字体及对应后备字体 |
| 内容宽度 | 正文最大宽度 560–1200 px；窗口较窄时自动收缩 |
| 段落间距 | 0.5–3 em，随正文字号缩放；字号与行距仍可单独调整 |
| 阅读主题 | 浅色、深色、护眼三种主题，覆盖阅读区域、工具栏、查词面板与弹窗 |
| 专注模式 | 隐藏主导航和顶部应用栏；阅读工具栏保留，可随时退出或打开查词 |
| 全屏阅读 | 点击「全屏」或按 G，由浏览器进入全屏；再次点击或按 Esc 退出。浏览器不支持时会提示使用专注模式 |
| 单栏与双栏 | 双栏按每行先左后右阅读，再向下阅读；正文区域不足 680 px 时自动显示单栏，保留双栏偏好 |
| 段落编号 | 在正文左侧显示编号，编号不混入复制的正文和单词语境 |
| 目录导航 | 按真实段落生成目录，以原文开头作预览；点击定位，不修改文章地址 |
| 快捷键 | F 专注、G 全屏、T 目录、S 设置、N 编号、C 单双栏、[ / ] 上下段、− / + 字号、空格 / Shift 空格翻屏、Home / End 首尾、? 帮助 |
| 手机手势 | 在正文中向左轻扫到下一段，向右轻扫到上一段；上下滚动、长按选词和双指缩放保持浏览器行为 |

设置自动保存在本机 SQLite 数据库，刷新页面或重新运行后继续生效；全屏必须由用户主动开启。阅读设置提供「恢复默认」，保存失败时可以重试。

快捷键在输入框、按钮、链接、可编辑区域和弹窗中不会触发，也不会覆盖 Ctrl、Command 或 Alt 组合键。可分别关闭快捷键与手机手势。Esc 保留为退出或关闭操作。

调整字体、间距、宽度、排版及窗口大小时，阅读器按当前段落及段内位置恢复视图；重新打开文章时仍使用原有阅读位置记录。改变排版本身不会增加已读进度。目录跳转和正常滚动继续记录阅读位置。

## 06 阅读流畅性设计

文章工具栏下方可切换「流畅阅读 / 精读模式」，并打开「本段生词」或「待查词」。默认使用流畅阅读。

| 功能 | 使用方式 |
| --- | --- |
| 流畅阅读 | 点词或划词先暂存，不请求词典、不弹出释义；正文使用完整阅读空间 |
| 精读模式 | 点词打开查词卡片；任何模式都可通过工具栏「查词」主动输入查询 |
| 释义折叠 | 查词卡片默认折叠，点「展开释义」查看；可在阅读设置中调整默认行为。待查列表始终在展开时才查询 |
| 段落集中处理 | 含待查词的段末显示「读完此段 · 处理…」，也可打开「本段生词」。列表按段落筛选，逐词展开、收藏或移出 |
| 暂存待查词 | 按文章和段落保存到本机，刷新和重启后仍在；同一段落的相同单词不重复添加。手动查询的词归入「手动记录」 |
| 学习提示密度 | 阅读设置提供安静、适中、详细：安静隐藏正文标记与主动提醒；适中仅标记每段首次出现的学习词；详细标记所有学习词并显示辅助说明 |
| 已掌握词减少提示 | 默认不主动标记已掌握词；可关闭该选项。手动点词、查词、暂存仍然有效 |
| 查词后保持位置 | 查词面板不挤动正文；关闭集中处理面板或点击「继续阅读」回到原处。异步释义返回不会把正在滚动的读者拉回旧位置 |
| 阶段性学习提醒 | 默认每 10 分钟前台活跃阅读显示轻提示，不抢焦点；可整理待查词、5 分钟后提醒或继续阅读。设置范围 0–60 分钟，0 关闭 |

提醒计时按本次打开文章累计，离开文章后重新开始；页面隐藏、弹窗、查词浮层、查词输入焦点或超过 60 秒无操作时暂停。安静档不主动提醒。滚动或跳段不会被当作已读确认，也不会自动把待查词标记为掌握。

暂存只记录单词和原文语境，不会自动加入生词本。收藏待查词与移出待查列表在同一事务中完成；已收藏的词保留原释义、笔记和掌握度。未收录的词可手填释义；查询或保存失败时保留记录并提供重试。

## 24 导出与外部工具联动

重新安装 `requirements.txt` 中的依赖并运行 `app.py`，打开侧栏 **「导出与联动」**。导出在本机完成，无需 AI 密钥或笔记工具账号，也不会产生 AI 调用费用。新增运行依赖为 `openpyxl`、`reportlab`、`genanki`。

| 内容 | 支持的文件与功能 |
| --- | --- |
| 生词本 | CSV、Excel（.xlsx）、JSON、Markdown、PDF；包含音标、词性、释义、掌握度、语境、学习笔记和来源 |
| 笔记与收藏 | CSV、Excel、JSON、Markdown、PDF；涵盖高亮、段落书签、页边批注、句子收藏、语法点、主题笔记、表达素材和知识卡片；保留标签、摘录和来源状态 |
| Anki 卡片 | 生词和知识卡片导出为 `.apkg`，可自定义牌组名称；正面是单词或卡片问题，背面包含释义 / 答案、语境和来源 |
| 学习报告 | 选择起止日期，导出 PDF、Excel、CSV、JSON、Markdown；统计阅读时长、完成次数、打卡、连续天数、新增生词与笔记，附每日明细 |
| 阅读清单 | 下载独立 HTML 文件分享，或复制 Markdown 清单；同时支持 CSV、Excel、JSON、PDF。只含文章信息和来源链接 |
| Obsidian | ZIP 笔记包：Markdown、标签、索引、相关原文摘录及往返链接 |
| Notion | ZIP 导入包：Markdown 页面、索引和 `records.csv`，可导入页面或数据库 |
| 数据接口 | 默认关闭；生成只读 Bearer 令牌后，本机脚本可分页读取生词、笔记、阅读清单和学习报告 |

先选择内容和筛选条件，点击「更新预览」，再选择格式和导出范围。可导出所有匹配项，也可勾选部分条目；「勾选已加载」只勾选当前已加载的记录，更多记录通过「加载更多」获取。更改筛选后需要重新预览。空结果不会生成空文件，失效勾选会提示重新选择。生成失败会保留筛选和勾选；「取消生成」会取消浏览器下载，本机已经开始的文件处理可能仍会完成。

单次最多 5000 条、8 MB 序列化文本，超过时请筛选或分批导出。JSON 保留标签数组和 UTF-16 原文位置字段；来源文章已删除时，笔记摘录仍可导出。CSV 使用 UTF-8 BOM，并对可能被表格软件当作公式的文本添加前置单引号；Excel 使用字面文本单元格。Excel 长文本完整保留，超长内容可在编辑栏查看，或选择 PDF / Markdown 阅读。PDF 自动分页，优先使用本机中文字体；可设置 `MARGIN_PDF_FONT` 为支持中文的 TTF / TTC 路径。字体仍未覆盖的少见字符会显示 `[U+编号]`，JSON 和 Markdown 保留原字符。

笔记导出读取第 19 项的 `knowledge_items` 数据，不依赖其编辑器模块。在尚未合入第 19 项的基础版上，笔记列表为空，生词、报告和阅读清单仍可正常导出；合入第 19 项并添加记录后即可导出笔记。导出模块不会创建或修改笔记表。

学习报告使用北京时间，默认最近 30 天，单次最多 366 天。阅读时长与完成次数来自所选日期的打卡记录，完成次数不是去重文章数；连续打卡只在本区间内计算。「新增」指区间内创建且当前仍保留的记录；掌握分布为导出时现状，不能作为历史掌握度快照。

### 导入外部工具

- **Anki**：选择「Anki 卡片包」，下载后在 Anki 使用「文件 → 导入」打开 `.apkg`。笔记导出会自动筛选「知识卡片」，普通笔记可先在知识整理中制成卡片。同一数据库、同一记录使用稳定 GUID，便于重复导入时更新；更新方式仍受 Anki 导入选项影响。导出不会修改本项目掌握度，也不会把 Anki 复习进度同步回来。
- **Obsidian**：解压 ZIP，将文件夹放入你的 Obsidian 仓库，打开 `index.md`。`words/` 或 `notes/` 保存记录，`sources/` 保存本次涉及的原文摘录，支持跳转与返回。
- **Notion**：在「导入 → Markdown 与 CSV」中选择 ZIP，也可解压后分别导入 Markdown 或 `records.csv`；CSV 可作为数据库。导入后按 Notion 提示检查页面链接。
- **分享阅读清单**：把下载的 HTML 文件发给他人即可独立打开；有公开来源的文章可以点击标题访问。清单不附带原文正文，个人导入且无公开链接的文章需另行提供。

Obsidian 和 Notion 文件都是导出快照，不会自动同步。重复导入时需在对应工具中自行选择更新或去重；建议每次使用独立文件夹，避免覆盖已有笔记。

### 本机只读数据接口

在「导出与联动 → 数据接口」生成令牌，只在生成时显示一次；可显示、复制、重置或撤销。明文不会保存在浏览器存储或数据库中，数据库仅保存校验哈希、尾号和创建时间。重置 / 撤销后旧令牌立即失效。接口只在程序运行时可用，默认仍监听 `127.0.0.1`，不提供公网地址和跨域读取。

所有数据接口使用 `GET`，路径前缀为 `/api/integrations/v1/`，需要请求头 `Authorization: Bearer YOUR_TOKEN`：

| 路径 | 筛选参数 |
| --- | --- |
| `vocabulary` | `query`、`mastery`（new / learning / mastered）、`article_id`、`from`、`to` |
| `notes` | `query`、`kind`、`tag`、`article_id`、`from`、`to` |
| `reading-list` | `query`、`read_status`（unread / reading / completed）、`from`、`to` |
| `report` | `from`、`to` |
| `schema` | 返回版本、资源、筛选和分页说明 |

日期采用 `YYYY-MM-DD`，包含起止两天；列表日期筛选对应记录创建日期。列表按 ID 升序，`limit` 默认为 100、范围 1–200；下一页将 `next_cursor` 作为 `after`，`next_cursor=null` 表示末页。返回 `schema_version`、`dataset`、`generated_at`、`filters`、`count` 和 `items`；报告则返回 `report` 对象。错误响应为 `{"error":"说明"}`：401 表示未启用或令牌无效，400 表示参数无效，404 表示资源不存在。

Python 调用示例：先在本机设置环境变量 `MARGIN_READ_TOKEN`，然后读取所有已掌握生词。

```python
import json
import os
from urllib.parse import urlencode
from urllib.request import Request, urlopen

after = 0
while True:
    query = urlencode({"mastery": "mastered", "limit": 100, "after": after})
    request = Request(
        "http://127.0.0.1:5000/api/integrations/v1/vocabulary?" + query,
        headers={"Authorization": "Bearer " + os.environ["MARGIN_READ_TOKEN"]},
    )
    with urlopen(request, timeout=30) as response:
        page = json.load(response)
    for word in page["items"]:
        print(word["word"], word["meaning"])
    after = page["next_cursor"]
    if after is None:
        break
```

程序还提供页面使用的 `GET /api/exports/options`、`POST /api/exports/preview` 和 `POST /api/exports/file`。后两者接受 JSON，例如 `{"dataset":"notes","format":"md","filters":{"tag":"写作"},"ids":[1,2]}`；`ids` 省略时导出全部匹配记录。此组接口用于本机页面操作，脚本集成建议使用上面的令牌接口。

本项测试位于 `tests/test_exports.py` 和 `tests/test_exports_browser.cjs`。安装 Playwright 后可运行 `node --test tests/test_exports_browser.cjs`，可通过 `EXPORT_TEST_BROWSER=msedge` 选择 Edge，通过 `EXPORT_TEST_PYTHON` 指定项目解释器。测试使用临时数据库，覆盖全部导出格式、内容保真、筛选与分页、Anki 标识、分享范围、令牌轮换与撤销、下载取消 / 失败恢复，以及桌面和手机布局。

## 使用流程

1. 打开示例文章，或通过「导入文章」添加英文材料。粘贴导入至少需要 40 个英文单词。
2. 在阅读设置中调整字体、字号、间距和主题，选择流畅阅读或精读模式。
3. 流畅模式中先暂存生词，读完一段再展开释义、加入生词本；精读模式可随时点词查阅。也可以手动添加词条。
4. 在「我的生词」中标记掌握度，按需编辑或删除词条。掌握度只记录学习状态。
5. 阅读结束后点击文章末尾的「标记为已读」，在「学习足迹」查看日历与累计阅读情况。

## 实现说明

### 阅读与记录

精读模式下，宽屏查词结果显示在正文右侧；流畅模式、窄屏、专注或全屏模式使用可关闭的浮动面板。阅读设置保存在本地数据库。

阅读时每约 15 秒保存一次，离开阅读器时也会保存。最大阅读进度不会因向上滚动而减少；最近阅读位置单独记录，重新打开文章时恢复。滚动最多记录到 99%，点击「标记为已读」后更新为 100%。

计时仅在页面前台、没有弹窗、最近 60 秒内有点击 / 滚动 / 键盘等操作时累计，属于活跃阅读时间的近似值。日期采用北京时间。异常断网或突然关闭进程时，最后尚未提交的一小段记录可能丢失。

### 文章获取与词典

网页提取会识别正文段落并过滤导航、脚本等。登录、付费或动态加载页面可能无法自动提取，此时可以粘贴正文。内置文章为项目原创教学示例，并非真实媒体报道的转载。

查词优先使用 `data/dictionary.json` 中的英汉词库，并处理一些常见词形；未收录的词联网查询 Free Dictionary API，返回英英释义并缓存。没有查到时会明确提示，允许手动填写释义。

### 难度标注

按平均句长和近似音节数计算 Flesch Reading Ease：

```text
206.835 - 1.015 × 平均句长 - 84.6 × 平均每词音节数
```

参考映射：85 及以上 A2、65–85 B1、45–65 B2、25–45 C1、低于 25 C2。该等级只是选文参考，不是正式 CEFR 测评。阅读时长按每分钟 180 词估算。

```text
│   ├── reading-flow.css      # 学习节奏、提示密度和面板样式
│   ├── exports.js            # 导出中心、预览、下载与令牌管理
│   ├── exports.css           # 导出中心与手机布局
│   ├── style.css             # 桌面与窄屏样式
│   └── favicon.svg
├── tests/                   # 基础功能、迁移与阅读设置测试
└── instance/margin.sqlite3   # 首次运行自动创建的本地数据库
```

当前数据库使用 `articles`、`vocabulary`、`pending_words`、`checkins`、`settings`、`dictionary_cache` 六张业务表。升级到 06 会自动创建待查词表，沿用原有阅读设置和学习数据。

从旧版升级时，程序会先备份原库为 `instance/margin-before-basic.sqlite3`，再清理已移除功能的表和字段，保留文章、生词、掌握度、笔记、阅读进度、打卡记录和支持的阅读设置。该转换只在检测到旧表结构时执行。基础版升级到阅读器扩展使用原有设置表，新增设置缺省时自动采用默认值。

删除文章会保留已收藏词汇与历史阅读统计，并清理该文章的待查词。备份个人数据时，先停止程序，再复制 `instance/margin.sqlite3`。

## 测试

在 PyCharm 的 Terminal 中运行：

```bash
python -m unittest discover -s tests -v
```

测试使用临时数据库，外部网络请求使用模拟响应，不修改个人学习数据。覆盖基础接口、持久化、查词缓存、词条管理、阅读设置边界与原子保存、异常设置回退、待查词去重与文章隔离、收藏事务与旧数据升级、打卡统计，以及已移除接口不可访问的检查。

可选的前端逻辑回归测试需要 Node.js 20 或更新版本，无需安装 npm 依赖：

```bash
node --test tests/test_frontend.cjs
```

这组测试运行真实的前端脚本，使用最小 DOM 替身和模拟请求，覆盖删除失败后继续保存、断网后计时补存、并发保存、划词查词及生词表单校验。它不替代真实浏览器中的布局和端到端交互检查；运行应用本身仍然只需要 Python。

可选的真实浏览器检查使用 Playwright，仍只操作临时数据库：

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node --test tests/test_reading_flow_browser.cjs
```

浏览器检查覆盖流畅/精读模式、释义折叠、段落待查词的刷新恢复与收藏、提示密度和已掌握词、网络失败重试、阶段提醒，以及桌面和手机视口下的阅读位置。异步列表更新会保留正在编辑的释义、焦点和光标；段末按钮出现或消失时按原文词语保持阅读位置。

本项目为本地单用户版本，默认仅监听 `127.0.0.1`。
