# ForeignNewsReaderAssistant

**Margin 知刊 · 外刊学习助手**

使用 **Python + Flask + SQLite** 完成赛题 1 的五项基础要求。前端使用原生 HTML / CSS / JavaScript，无需 Node.js 或单独的数据库服务。

本项目使用本地 **PyCharm 直接运行 app.py**，当前包含五项基础功能和扩展 05–09、13–14、16–17、21–22，不提供批处理启动脚本。

## 在 PyCharm 中运行

1. 用 PyCharm 打开 `ForeignNewsReaderAssistant` 项目文件夹。
2. 在 **Settings → Project → Python Interpreter** 中选择 Python 3.10 或更新版本，推荐 Python 3.12。
   - 项目已有虚拟环境时，可选择 `.venv/Scripts/python.exe`。
   - 也可以通过 PyCharm 为项目新建虚拟环境。
3. 在 PyCharm 的 Terminal 中安装依赖，确认终端使用项目解释器：

   ```bash
   python -m pip install -r requirements.txt
   ```

4. 右键根目录的 **app.py → Run 'app'**。
5. 在浏览器打开 **http://127.0.0.1:5000**。

在 PyCharm 中点击停止按钮即可关闭服务。下次运行时，已保存的学习记录会自动加载。首次安装依赖需要联网。

数据与示例文件路径均相对于项目代码所在位置解析，不依赖工作目录。如果端口被占用，可以在 Run Configuration → Environment variables 中设置 `PORT=5001`，再访问对应端口。

## 基础功能

| 赛题要求 | 当前实现 |
| --- | --- |
| 文章获取与阅读器 | 公开网页链接提取、粘贴英文正文、内置 5 篇原创示例；分类与搜索；字号 16–28 px、行距 1.4–2.4 倍 |
| 划词查词与基础释义 | 单击或划选一个英文单词；显示音标、词性、释义；支持输入单词查询 |
| 生词本 | 收藏、手动添加、删除、编辑释义与笔记、搜索；手动标记初次遇见 / 正在学习 / 已掌握 |
| 阅读进度与打卡日历 | 自动保存进度和最近阅读位置、标记已读、活跃阅读自动打卡、手动打卡、月历及阅读统计 |
| 文章难度标注 | 估算易读度，标注 A2 / B1 / B2 / C1 / C2 参考等级，显示词数与预计阅读时长 |

## 06 阅读流畅性设计

文章工具栏下方可切换「流畅阅读 / 精读模式」，并打开「本段生词」或「待查词」。默认使用流畅阅读。

| 功能 | 使用方式 |
| --- | --- |
| 流畅阅读 | 点词或划词先暂存，不请求词典、不弹出释义；正文使用完整阅读空间 |
| 精读模式 | 点词打开查词卡片；任何模式都可通过工具栏「查词」主动输入查询 |
| 释义折叠 | 查词卡片默认折叠，点「展开释义」查看；可在阅读设置中调整默认行为。待查列表始终在展开时才查询 |
| 段落集中处理 | 含待查词的段末显示「读完此段 · 处理…」，也可打开「本段生词」。列表按段落筛选，逐词展开、收藏或移出 |
| 暂存待查词 | 按文章和段落保存到本机，刷新和重启后仍在；同一段落的相同单词不重复添加。手动查询的词归入「手动记录」 |
| 学习提示密度 | 阅读设置提供安静、适中、详细：安静隐藏正文标记与主动提醒；适中仅标记每段首次出现的学习词；详细标记所有学习词并显示辅助说明 |
| 已掌握词减少提示 | 默认不主动标记已掌握词；可关闭该选项。手动点词、查词、暂存仍然有效 |
| 查词后保持位置 | 查词面板不挤动正文；关闭集中处理面板或点击「继续阅读」回到原处。异步释义返回不会把正在滚动的读者拉回旧位置 |
| 阶段性学习提醒 | 默认每 10 分钟前台活跃阅读显示轻提示，不抢焦点；可整理待查词、5 分钟后提醒或继续阅读。设置范围 0–60 分钟，0 关闭 |

提醒计时按本次打开文章累计，离开文章后重新开始；页面隐藏、弹窗、查词浮层、查词输入焦点或超过 60 秒无操作时暂停。安静档不主动提醒。滚动或跳段不会被当作已读确认，也不会自动把待查词标记为掌握。

暂存只记录单词和原文语境，不会自动加入生词本。收藏待查词与移出待查列表在同一事务中完成；已收藏的词保留原释义、笔记和掌握度。未收录的词可手填释义；查询或保存失败时保留记录并提供重试。

## 使用流程

1. 打开示例文章，或通过「导入文章」添加英文材料。粘贴导入至少需要 40 个英文单词。
2. 在阅读设置中调整字体、字号、间距和主题，选择流畅阅读或精读模式。
3. 流畅模式中先暂存生词，读完一段再展开释义、加入生词本；精读模式可随时点词查阅。也可以手动添加词条。
4. 在「我的生词」中标记掌握度，按需编辑或删除词条。掌握度只记录学习状态。
5. 阅读结束后点击文章末尾的「标记为已读」，在「学习足迹」查看日历与累计阅读情况。

## 07 词典与词汇知识

阅读页查词输入框支持 1–6 个英文单词组成的单词、短语或习语（最多 60 个字符）；也可在同一段中划选短语。在流畅模式下先暂存，在精读模式下打开查词卡片。短语可以加入生词本，保留原文语境，并按实际情况标记掌握程度。

“查询词典”和待查词列表中的“待查词词典”使用同一个可持久化的词典偏好：

| 选项 | 行为 |
| --- | --- |
| 自动 · 离线优先 | 先查离线英汉与短语库，未收录时请求在线英英词典 |
| 离线英汉 | 只使用随项目提供的数据，不请求在线服务 |
| 在线英英 | 明确查询 Free Dictionary API；已查询结果可用本地缓存 |

当前随项目提供 **12,012 个不重复离线词头**（原有 175 条学习释义优先，另含 ECDICT 12,011 个词头）和 **50 条原创短语、习语**。使用词库中真实的变化形式还原规则与不规则词形，也支持 `took into account → take into account` 等已收录短语的首词变化；不会把任意句子自动翻译成短语。

展开释义后，可进一步展开“词汇知识”，查看常见搭配、同义词与反义词、易混词辨析、词根词缀、词族、词形变化，以及词频和词汇等级。当前原创学习笔记覆盖 32 个词条、31 个词族、20 组易混词，并为 30 个词条提供明确标注的英美音标。近义词、反义词也会使用在线词典返回的数据；相关词和词形按钮可继续查词。

词频、考试标签与变化形式来自 [ECDICT](https://github.com/skywind3000/ECDICT)，保留原始 BNC / 当代语料排名及考试或核心词汇标记；它们不是实时词频，也不是 CEFR 等级。没有明确地区信息的音标显示为“未区分地区”；没有数据的学习项明确标记缺失，不生成虚构的排名、等级或词源。构词笔记用于学习联想，不代替完整词源分析，同义词需结合具体义项使用。

ECDICT 子集来源版本为 `39cfb9672c0906b63569e0453c2e6abfb9ab182a`。生成规则是按 BNC / 当代语料中较小的正排名选取 12,000 个小写词头，再补入学习笔记用到的词。数据来源、版本和选择规则保存在 `data/dictionary-extra.json`，上游 MIT 许可保存在 `data/ECDICT-LICENSE.txt`。从本地上游检出目录可重建：

```bash
python data/build_dictionary.py /path/to/ECDICT
```

在线词典使用 [Free Dictionary API](https://dictionaryapi.dev/)。缓存按词典和数据版本隔离，离线查询不会被在线缓存覆盖；损坏的缓存会忽略并重新查询。网络失败时保留手动填写和重试入口，查询和切换词典不改变掌握程度。升级沿用现有数据库表，保留原有文章、生词、笔记和阅读记录。

## 08 AI 语境释义与 09 翻译辅助

在阅读工具栏打开“AI 语境”或“翻译”。同段划选单词、短语或句子后，也可使用浮动工具条；查词卡片提供“结合原文释义”和“翻译原文表达”。面板会先显示选中的原文，点击生成才请求模型，不会在进入文章时自动发送正文。

| 功能 | 使用方式与保存行为 |
| --- | --- |
| 当前语境释义 | 根据具体原文位置与邻近段落判断含义；同词在不同位置独立处理；显示可在原文中核对的引用 |
| 多义、短语、隐喻与习语 | 展示义项辨析、短语整体含义、修辞解释，以及语域和语气；不适用的项目可为空 |
| 上下文指代 | 给出指代表达、可能指向和原文依据；信息不足时应说明不确定性 |
| 文章主题例句 | 提供 1–2 条模型新编例句与中文解释，明确标记为生成例句，不作为原文引文 |
| 解释深度 | 入门、进阶、深入三档，保存在阅读设置中，按所选水平独立缓存 |
| 单词、句子与段落翻译 | 按原文位置选择范围，同时保留原文、直译和意译，可按需折叠译文 |
| 全文翻译 | 逐段生成并保存；超过 2,800 个 Unicode 字符的段落会分片；显示进度，支持停止与后续继续，已完成片段不重复请求 |
| 译文学习 | 查看直译与意译差异、重点表达、文化背景说明和不确定之处 |
| 收藏与修订 | 收藏译文、修改直译和意译、添加修订笔记；刷新或重启后保留；模型初稿独立保存，可载入初稿后再决定是否保存 |

修改中的内容会保留在本次阅读页面的草稿中，界面明确提示尚未保存。刷新或离开阅读页前，请保存希望保留的修订。保存等待期间继续输入的内容仍保持为待保存草稿；异步新增结果会保留输入焦点、光标和文本框内部滚动位置。多页面修订采用版本校验，发生冲突时显示最新记录并保留本页输入，核对后由用户再次保存。

全文生成失败后可再次点击生成，面板会继续缺失片段。停止后不再提交后续请求；已经到达服务器的当前请求可能继续完成，重新打开面板会读取已保存内容。同一进程内同一片段的并发生成会被拦截，失败不写入成功缓存。模型、服务配置、提示版本、学习水平或原文变化时使用不同的缓存；编辑过的译文不会被再次生成覆盖。原文变化后旧结果会标注过期，收藏中仍可核对其保存时的原文。

### 配置模型服务

AI 服务由服务器端调用 [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)，使用 [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses) 获取结构化结果；也支持提供同等 Responses 与 JSON Schema 能力的 HTTPS 兼容服务。模型名称由使用者指定，本项目不会自动选择或切换模型。

启动 Python 前，在 PyCharm 的 **Run → Edit Configurations → Environment variables** 中设置：

```text
MARGIN_AI_API_KEY=你的模型服务密钥
MARGIN_AI_MODEL=你的模型名称
```

兼容服务可另设 `MARGIN_AI_BASE_URL`，默认值为 `https://api.openai.com/v1`，不要在末尾加 `/responses`。参考文件为 `ai.env.example`，程序不会自动加载该文件。修改环境变量后需重新启动服务。不要提交实际密钥文件；本地 `ai.env` 已加入忽略规则。

密钥只从服务器环境变量读取，不返回浏览器、不写入学习数据库。模型请求使用 `store: false`、不携带历史对话、不自动重试；正文按不可信阅读材料与任务指令分开传入。点击生成会将所选片段、文章标题和有限的邻近上下文发送给配置的服务。全文需要多次调用，使用者应按其服务账号的额度与费用安排使用。

未配置模型时，界面会显示设置入口并停用生成；已保存结果仍可查看与修订。超时、额度不足、拒答、未完成输出、格式异常或引用不符会明确报错，保留重试入口，不把模板或离线词条包装成 AI 结果。AI 内容用于学习，语义、指代和文化解释仍需结合原文核对；结构校验与引文校验不等于语义正确性保证。

## 13 生词本扩展

在「我的生词」中创建标签、分组和自定义词书，再进入词条编辑窗口勾选归属。单词、短语和句型可分别收藏、筛选；支持多个义项、多个原句及译文，第一义项作为主释义。阅读器中再次收藏已有词条会追加当前原句；相同原句按文本去重，保留首次来源。

学习笔记可追加「阅读笔记」「易混词对比」「句型练习」模板，也可自建笔记块。先保存词条，再添加例句正反面卡片、本地图片或音频。支持 PNG/JPEG/WebP 与 MP3/WAV/OGG，每文件最多 2 MB，每词条最多 20 张卡片；媒体与资料一起保存在 SQLite，无需外部图片或音频服务。每词条最多 30 个义项、30 个原句、30 个笔记块和 100 个分类。

勾选 2–31 个词条后使用「合并词形」，人工选择保留的目标词。界面提供可用的词典原形提示，不会自动合并易混词。原句、义项、分类、卡片和历史记录汇总到目标词；其余词条成为可识别的词形。保留目标词的手动掌握度与复习计划。句型只能与句型合并；超出容量或词条版本变化时整次操作不写入。

「批量导入」先验证、预览，再确认写入，单次 1–500 条。支持 UTF-8 JSON 和 CSV，可跳过已有词条，或追加资料；追加不会覆盖现有笔记、手动掌握度或复习计划。整批失败时不会部分导入。CSV 表头至少含 `word,meaning`，还支持 `phonetic,part_of_speech,note,entry_kind,tags,groups,books,context`；分类名用 `|` 分隔，包含逗号或换行的单元格用 CSV 引号包围。

JSON 可导出当前筛选或勾选的词条，包括义项、原句、词形、笔记与分类；可选择包含媒体。CSV 仅导出基础字段与分类，并为可能被表格软件当作公式的单元格加前导撇号。完整迁移词条请使用 JSON，例如：

```json
{"entries":[{"word":"take into account","entry_kind":"phrase","meaning":"考虑","contexts":[{"text":"We take into account every cost.","translation":"我们考虑每项成本。"}],"collections":[{"kind":"book","name":"经济外刊"}]}]}
```

JSON 文件最多 20 MB，含媒体导出过大时可减少勾选或关闭媒体。跨库导入保留原文和文章标题，不沿用另一数据库的文章编号。词条导入以新复习计划开始，不恢复导出文件中的历史调度字段；已有词条的计划不变。完整备份包含复习日志时，请停止程序后复制 SQLite 数据库文件。

## 14 间隔复习 SRS

「间隔复习」显示到期数、待学新词、重学数及今日作答，展开「今日可学列表」可选择当前批次的词条，也可按词书、标签或分组过滤。默认每日新词 10 个、复习 50 个，可分别设为 0–200 与 0–2000；每批最多返回 200 张，完成后自动读取下一批。限额为全局每日不同词条数量，同一天的遗忘重学不会重复消耗限额。统计与每日重置按北京时间计算。

同一词条的四种练习共用一个复习计划：

- 正反面：先回想含义、搭配与用法，翻面后查看多义项和卡片。
- 原句挖空：匹配目标词及已合并词形，挖空所有匹配处；没有匹配原句时可切换正反面。
- 听音辨词：优先播放已保存的音频，否则使用浏览器本机英文语音。正面隐藏单词；没有英文语音或播放失败时会明确提示，可上传音频或切换模式。
- 拼写回忆：根据释义拼写，翻面后核对；接受已合并词形、大小写和常见撇号差异。结果供自评，不自动提交评分。

翻面后选择「忘记 / 困难 / 记住 / 轻松」（SM-2 质量 0 / 3 / 4 / 5）。采用 [SuperMemo SM-2](https://www-beta.supermemo.com/archives1990-2015/english/ol/sm2) 的间隔和难度因子：第一次成功后 1 天，第二次 6 天，之后为上次间隔乘以评分前的难度因子并向上取整；难度因子最低 1.3。遗忘加入 10 分钟重学步骤，然后从 1 天重新开始。累计遗忘 8 次自动标为困难词，也可手动管理。暂停不删除计划，恢复后按原到期时间继续。

复习评分与手动掌握度独立保存，不会自动把词标成「已掌握」。评分确认失败可重试同一请求，服务器只计一次；过期卡片和另一页面修改过的词条需重新加载。词条编辑也检查版本，冲突时保留本页草稿，核对更新后再保存。

## 16 听力与口语训练

在侧栏打开「听说训练」，或从文章中的「听力与口语训练」进入，选择段落和当前原句。支持盲听与显示原文切换、逐句听写、关键词填空，以及忽略大小写和标点的词序差异对比。原句保留原文位置，超长句会按词边界分成不超过 600 字符的片段。

「精听循环」可设置当前句到循环终点的 A–B 范围、1–10 遍、0–10 秒句间停顿、0.6–1.5 倍语速及本机英文语音。已上传的对应原音优先播放，否则使用浏览器的本机英文语音；无可用语音时明确提示上传原音，不模拟播放。支持 WebM、OGG、WAV、MP3、M4A，每份原音或录音最多 6 MB。

「跟读录音」先在本页预览，可交替播放原句与自己的录音；「影子跟读」要求先勾选已戴耳机，再一边播放原句一边录音。麦克风只在点击开始录音后申请，录音最多 2 分钟。停止、离开页面、页面隐藏或取消等待许可时会释放设备；迟到的麦克风许可也不会在离开后继续录音。不支持录音或许可被拒绝时可选择本地录音文件。

英文语音识别为**可选且默认关闭**。勾选后由浏览器的识别能力提供文字，浏览器可能通过其识别服务处理音频；不支持、无结果或识别失败时仍可保存录音、手动填写核对文字。录音仅在点击「保存并查看反馈」后写入本机 SQLite。未保存录音可先下载；刷新或离开前请保存需要保留的内容。

反馈展示原文与识别文字的匹配、遗漏、插入、替换，并给出本机音频能量估算的发声语速、停顿比例和停顿次数。**识别差异不等同专业声学发音评分**，设备噪声、识别误差和原音串入都会影响结果；没有文字或有效发声估计时不会生成虚假的分数；有效录音过短时也不估算语速。上传录音不进行虚构的语速分析，无分析数据时明确显示缺失。听写、填空和跟读均保留学习记录与原文快照，保存失败可重试同一记录编号，避免重复写入。

录音依赖 [MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder) 与 [getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)，需使用本机 localhost 或 HTTPS；语音识别的可用性由浏览器决定。生成的录音预览使用本地 Blob，服务端不自动上传录音到 AI。

## 17 阅读练习与测验

「阅读测验」提供八种题型：阅读理解选择、判断、段落匹配、完形填空、词义辨析、句子排序、文章主旨和推断。内置五篇原创文章各配套 8 题，共 40 题，附解析与可核对的原文依据；题库在 `data/reading-exercises.json`，按文章内容匹配，改动正文后不会误用旧题。

其他导入文章的「原文练习」离线生成可核对的关键词完形、段落定位和句序题，不把机械抽取包装成语义推断题。也可手动添加 1–12 题，填写题干、选项、答案、解析和原文依据；填空题填回答案、排序题按正确顺序拼回后必须能还原原文。

已配置第 08–09 项的 AI 服务时，可点击「AI 出题并练习」，明确发送所选文章并生成八类题。文章上限 16000 字符，结果检查题型、选项、答案结构和原文引用，失败不保存；同一文章、模型配置和出题版本会复用已有题目，避免重复调用。AI 题目用于学习，不代表题意与答案已通过人工审定，需结合原文核对。未配置服务时，离线与手动练习仍可使用。

练习支持 0–60 分钟限时，0 表示不限时；选择和排序选项会重新排列。作答自动保存到服务器，未确认的草稿也暂存在当前浏览器标签页，刷新可恢复。多页面同时修改会保留本页草稿并要求核对版本。正确答案和解析在交卷前不由会话接口返回。

**截止时间和最终评分由服务器控制**。到时按截止前已保存的作答交卷，迟到的答案不能修改成绩；断网或确认丢失后可重试读取结果 / 提交，评分及错题只写入一次。限时按开始后的实际经过时间计算，离开页面不会暂停；结果显示得分、用时、各题型正确率、作答、参考答案与原文依据。

答错或未作答的题进入「错题本」，支持词汇、语法、细节定位、推断主旨、时间不足、审题疏忽等错因分类、反思笔记与解决状态。勾选 1–20 题可重新练习，答对后标为已解决，再次答错会重新进入待复习，并保留自己的错因与笔记。界面显示最近 200 条错题，练习历史展示最近 100 场；数据继续保存在本机。

「阶段测评」从 2–5 篇文章组合题目，记录本次总分、用时及分题型表现；历史页可查看各场结果与最近练习的题型汇总。不同文章和题目难度不同，练习分数不作为正式 CEFR 或标准化能力等级。删除原文章后，已完成的练习、错题、听说记录及录音仍保留各自快照。

## 21 个性化难度与推荐

侧栏「难度与推荐」可设置自评水平（A2–C2）、兴趣主题、单次阅读时间、估计阅读速度和挑战偏好。文章库展示前三篇推荐；阅读器的「个人难度与读后反馈」入口可查看当前文章的分析并反馈。推荐完全在本机计算，无需 AI 密钥或联网。

| 功能 | 行为 |
| --- | --- |
| 个人难度 | 综合文本易读度、自评水平、词频假设与自己的词汇记录，显示「轻松 / 适合 / 挑战」及估计用时 |
| 词汇分布 | 按词次区分手动已掌握、稳定复习、已记生词、常用词假设、超出词频假设和词库未覆盖；展示可先关注的词 |
| 选文推荐 | 从本地文章库按难度、兴趣与时间匹配排序，逐篇展示理由；支持主题、用时和已读筛选 |
| 难度反馈 | 「偏易 / 合适 / 偏难」按文章保存；「多推荐 / 少推荐这篇」独立保存，可在反馈记录中撤销 |
| 逐步调整 | 近 90 天至少 3 篇独立材料有有效记录后，小幅调整选文难度；可关闭自动调整，手动水平始终保留 |
| 偏好管理 | 刷新与重启后保留；多页面保存发生版本冲突时要求重新载入，避免覆盖；恢复默认偏好保留学习记录和反馈 |

首次使用采用默认 B1 与 180 词/分钟，界面明确提示设置偏好。**没有收藏的词不直接视为生词**；手动已掌握才进入确认覆盖率，SRS 连续成功至少 3 次且间隔至少 6 天单独计入稳定复习。词形使用词库中确证的变化关系；保留 `saw`、`news` 等独立词头的含义，不随意剥离词尾。短语和句型不会拆成已掌握单词，词形合并时保存的别名可以识别。

算法使用所选水平对应的启发式词频范围 1500 / 3000 / 6000 / 10000 / 16000，**这些范围不是 CEFR 官方词表或词汇量测评**。学习负荷将手动掌握、稳定复习、已记生词、常用词假设、超范围词和词库缺失分别以 0 / 0.1 / 0.75 / 0.06 / 0.55 / 0.4 加权，显示每 100 词的估算，不称为确切生词率。基本难度保留原 Flesch 估计，个人相对难度再结合词汇负荷；匹配分只用于本库排序。用时由正文词数除以用户设置的速度，不从停留时长推断阅读能力。

自动调整仅采用内置题库的首轮有效理解题（选择、判断、词义、主旨、推断）：至少作答 3 题并覆盖该篇 80% 的这类题；正确率至少 85% 或不超过 50% 分别提供增减信号，中间区间保持。重复作答、错题重做、机械定位题、未完成、空白交卷和未经人工审定的 AI / 手动题不用于提级。同一正文即使重复导入或同时有测验与反馈也只计一篇，难度反馈优先；信号最多使目标位置上下调整 0.6 档，不自动修改自评等级。兴趣调整不会刷新旧难度反馈的日期。

「少推荐这篇」会从推荐中隐藏文章，仍可在「反馈记录」恢复，也可照常在文章库阅读。正文改变后旧反馈失效，提交过期分析会被拒绝；删除文章会删除其推荐反馈。推荐操作不会修改阅读进度、打卡、生词掌握度或 SRS 计划。文章库规模或反馈不足时可能没有匹配内容，界面建议调整筛选或导入文章，不虚构外部推荐。

## 22 学习数据分析

侧栏「学习数据分析」提供周报、月报和年度回顾，可选择参考日期、切换上一期 / 下一期，或从「学习足迹」进入。周报从星期一到星期日，月报按自然月，年度回顾按自然年；日期均采用北京时间，闰年与跨年周会完整显示。

| 分析项 | 统计口径与使用方式 |
| --- | --- |
| 阅读量与时长 | 每日活跃阅读时长、首次完成篇数、可追溯完成文章词数、阅读日数；手动打卡不增加阅读量 |
| 阅读速度趋势 | 首读进度推进词数 ÷ 对应活跃计时，按保存段加权汇总；只有至少 10 秒且有首读进度推进的片段参与，手动标记完成不参与 |
| 词汇增长 | 新增、移除与词库累计三种曲线；包含短语、句型、批量导入，合并和删除会减少词库数量 |
| 掌握度分布 | 当前「初次遇见 / 正在学习 / 已掌握」条数及比例，明确标为当前快照，不冒充周期末历史状态 |
| 查词频率 | 主动查词次数、每日 / 每月趋势及查询最多的 20 个词或短语；暂存待查词不算已查询，未找到释义的主动查询仍计入 |
| 文章生词率 | 当前词库中待掌握词（含稳定复习但尚未手动掌握的词）在正文中的词次 ÷ 正文英文词次；词形使用词典确证关系或人工合并别名，短语不拆成已知生词 |
| 反复遇见词 | 记录正文中点词暂存或按段查词的实际位置；同词、同一篇正文的同一段落、同一天去重，跨段或跨日计为再次遇见，显示次数、正文数、天数 |
| 复习正确率 | 自评记住率为 SM-2 `grade ≥ 3` 的次数比例；拼写核对正确率单独统计有实际核对结果的拼写作答，不混用两者 |
| 遗忘情况 | 已学词再次未记住的次数与词条榜；首次学习未记住单独列出，当前困难词、暂停词另行显示 |
| 主题偏好 | 按所选周期内有记录的主题阅读时长排序，同时显示完成篇数与查词数；旧的全局时长不会被任意分配给某个主题 |
| 周 / 月 / 年报告 | 概览文字与指标、可交互图表、准确数据表；年报按月展示，按所有有效样本的总词数 / 总秒数计算速度，不平均各月速度 |
| 导出 | 下载带 UTF-8 BOM 的每日 CSV，附统计口径，未采集的查词和无速度样本保留空值，便于用 Excel 查看 |

图表可点选日期或使用键盘 Enter / 空格查看当日摘要，也提供精确数据表。手机端图表和宽表在各自区域横向滚动，页面本身不横向溢出。快速切换周期时，仅最新请求可以更新页面；读取失败保留带原日期的上一份报告并提供重试。

**历史数据范围**：升级时保留原阅读、词汇、笔记、复习记录，并补齐仍在词库的词条创建日期和仍有正文的已完成文章。无法找回升级前已删除词条的新增记录、已删除文章的正文词数、历史查词或历史阅读速度，因此不会伪造这些数据。查词图表对未采集日期显示缺失，卡片注明完整 / 部分覆盖；没有有效速度、复习或拼写样本时显示「暂无样本」。阅读时长按保存成功的北京时间归档，单次最多 60 秒，属于活跃计时近似值。

新阅读和查词活动保存文章标题、分类与正文哈希快照，删除文章后仍可统计此前已采集的活动；正文变化或删除后旧快照不计算当前生词率。文章表最多显示前 50 条正文记录，查询和重复遇见榜各显示前 20 项。未收藏、仅查过或词库没有收录的词不会直接被视为生词；已记生词率是可追溯下限，不是完整未知词率。阅读速度受滚动、跳段和重读影响，是进度推进估算，不代表正式能力测评。

前端每批阅读保存使用固定请求编号，确认丢失后重试原编号，避免重复增加阅读时间；新产生的时间和进度使用下一编号继续保存。主动查词单独记观察事件，不把后台词典 GET 或浏览缓存当作学习行为。查词统计失败会在当前浏览器标签页暂存，刷新后重试同一记录编号，恢复连接后继续保存；最多 500 条、7 天，关闭该标签页会清除未保存队列。过期、原文改变或已删除文章的迟到记录不补计。记录保存在本机，不上传外部分析服务，也不调用 AI。

## 实现说明

### 阅读与记录

精读模式下，宽屏查词结果显示在正文右侧；流畅模式、窄屏、专注或全屏模式使用可关闭的浮动面板。阅读设置保存在本地数据库。

阅读时每约 15 秒保存一次，离开阅读器时也会保存。最大阅读进度不会因向上滚动而减少；最近阅读位置单独记录，重新打开文章时恢复。滚动最多记录到 99%，点击「标记为已读」后更新为 100%。

计时仅在页面前台、没有弹窗、最近 60 秒内有点击 / 滚动 / 键盘等操作时累计，属于活跃阅读时间的近似值。日期采用北京时间。异常断网或突然关闭进程时，最后尚未提交的一小段记录可能丢失。

### 文章获取与词典

网页提取会识别正文段落并过滤导航、脚本等。登录、付费或动态加载页面可能无法自动提取，此时可以粘贴正文。内置文章为项目原创教学示例，并非真实媒体报道的转载。

查词由 `newsreader/dictionary.py` 处理，提供离线英汉、原创短语知识与可选择的在线英英词典；具体覆盖、数据来源与限制见上面的第 07 项。没有查到时会明确提示，允许手动填写释义。

### 难度标注

按平均句长和近似音节数计算 Flesch Reading Ease：

```text
206.835 - 1.015 × 平均句长 - 84.6 × 平均每词音节数
```

参考映射：85 及以上 A2、65–85 B1、45–65 B2、25–45 C1、低于 25 C2。该等级只是选文参考，不是正式 CEFR 测评。阅读时长按每分钟 180 词估算。

基础数据使用 `articles`、`vocabulary`、`pending_words`、`study_results`、`checkins`、`settings`、`dictionary_cache`。生词本扩展增加 `word_meta`、`word_collections`、`word_memberships`、`word_contexts`、`word_senses`、`word_notes`、`word_aliases`、`word_cards`，复习使用 `srs_cards` 与 `srs_events`；听说训练使用 `listening_audio` 与 `listening_attempts`，阅读练习使用 `reading_sets`、`reading_sessions` 与 `reading_mistakes`；个性化偏好使用 `learner_profile`，推荐反馈使用 `article_feedback`；学习分析使用 `learning_reading_events`、`learning_word_events` 与 `learning_lookup_events`，用 `analytics.started_at` 标记过程数据的起点；启动时为已有生词补齐资料与新词计划，重复启动不重置已保存的复习记录。升级时自动增建待查词和 AI 学习结果表，保留原有文章、生词、笔记、阅读设置和学习记录。AI 结果与译文属于对应文章，删除文章时会一并删除；生词本仍按原有规则保留。

从旧版升级时，程序会先备份原库为 `instance/margin-before-basic.sqlite3`，再清理已移除功能的表和字段，保留文章、生词、掌握度、笔记、阅读进度、打卡记录和支持的阅读设置。该转换只在检测到旧表结构时执行。基础版升级到阅读器扩展使用原有设置表，新增设置缺省时自动采用默认值。

删除文章会保留已收藏词汇与历史阅读统计，并清理该文章的待查词。备份个人数据时，先停止程序，再复制 `instance/margin.sqlite3`。

## 测试

在 PyCharm 的 Terminal 中运行：

```bash
python -m unittest discover -s tests -v
```

测试使用临时数据库，外部网络请求使用模拟响应，不修改个人学习数据。覆盖基础接口、持久化、查词缓存、词条管理、阅读设置边界与原子保存、异常设置回退、待查词去重与文章隔离、收藏事务与旧数据升级、打卡统计，以及已移除接口不可访问的检查。

可选的前端逻辑回归测试需要 Node.js 20 或更新版本，无需安装 npm 依赖：

```bash
node --test tests/test_frontend.cjs
```

这组测试运行真实的前端脚本，使用最小 DOM 替身和模拟请求，覆盖删除失败后继续保存、断网后计时补存、并发保存、划词查词及生词表单校验。它不替代真实浏览器中的布局和端到端交互检查；运行应用本身仍然只需要 Python。

可选的真实浏览器检查使用 Playwright，仍只操作临时数据库：

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node --test tests/test_reading_flow_browser.cjs
node --test tests/test_dictionary_browser.cjs
node --test tests/test_assistance_browser.cjs
node --test tests/test_wordbook_srs_browser.cjs
node --test tests/test_practice_browser.cjs
node --test tests/test_personalization_browser.cjs
node --test tests/test_analytics_browser.cjs
```

浏览器检查覆盖流畅/精读模式、释义折叠、段落待查词的刷新恢复与收藏、提示密度和已掌握词、网络失败重试、阶段提醒，以及桌面和手机视口下的阅读位置。异步列表更新会保留正在编辑的释义、焦点和光标；段末按钮出现或消失时按原文词语保持阅读位置。

词典浏览器检查使用真实 Flask 与临时 SQLite、受控在线词典响应，覆盖词典偏好、加载中切换与过期响应、词汇知识与词族跳转、划选短语暂存收藏、手动释义重试、HTML 转义和手机布局。它不依赖外部词典服务的可用性，不代表对真实外网连通性或每个第三方词条内容的逐条校对。

AI 学习检查使用真实 Flask、临时 SQLite 与真实浏览器，模型响应明确使用 `tests/ai_fixtures.py` 中的受控测试数据；模型传输、HTTP 错误、拒答、结构异常、截断和原文引用另有后端测试。覆盖原文定位与 Unicode 偏移、解释深度、逐段失败续译与停止、迟到响应、收藏与修订持久化、版本冲突、输入与滚动位置保留、无模型配置和手机深色布局。测试不会调用真实计费模型，不代表实际模型账号连通性或生成质量已经验证。
